Selim Trade Center — সংশোধিত চূড়ান্ত ফাইল

এই প্যাকেজে index.html মূল সফটওয়্যারের সর্বশেষ সংরক্ষিত সংস্করণ থেকে তৈরি।

এই সংশোধনে:
১. Login বাটন কাজ না করার কারণ—PDF প্রিন্টের CSS ভুল করে JavaScript string-এর মধ্যে ঢুকে পড়েছিল—তা ঠিক করা হয়েছে।
২. মাসিক ও বার্ষিক PDF-এ চার্ট ও মাধ্যমভিত্তিক সারাংশ বাদ দেওয়ার নিয়ম রাখা হয়েছে।
৩. A4 portrait, ১৫ মিমি মার্জিন এবং টেবিলের ১০pt ফন্টের প্রিন্ট CSS রাখা হয়েছে।
৪. কলামের ফাঁকা জায়গা কমিয়ে লেনদেনের টেবিল পৃষ্ঠা অনুযায়ী চলবে; পরের পৃষ্ঠায় টেবিলের হেডিং পুনরাবৃত্তির নিয়ম রাখা হয়েছে।
৫. সফটওয়্যারের অন্যান্য হিসাব ও ডেটা কাঠামো পরিবর্তন করার উদ্দেশ্য ছিল না।

ব্যবহার: ZIP Extract করে index.html ফাইলটি GitHub Pages repository-তে আগের index.html-এর বদলে আপলোড করুন।

যাচাই: ZIP integrity, inline JavaScript syntax এবং সংশোধিত CSS অবস্থান পরীক্ষা করা হয়েছে। বাস্তব Firebase login, live browser, PDF print preview বা Excel-এর runtime preview পরীক্ষা করা হয়নি। Google Fonts-এর জন্য ইন্টারনেট প্রয়োজন।
