SELIM TRADE CENTER — সংশোধিত প্যাকেজ

ফাইলসমূহ:
- index.html : সংশোধিত মূল সফটওয়্যার
- sw.js : আপডেটেড cache version
- manifest.webmanifest, icon-192.png, icon-512.png : PWA app icon/manifest

যে সংশোধনগুলো করা হয়েছে:
1. আগের A4 Landscape, পাশাপাশি ২ কপি মানি রিসিট/পেমেন্ট ভাউচার প্রিন্ট লেআউট ফিরিয়ে আনা হয়েছে। রিসিটের খাতের নাম “মাসিক ভাড়া” রাখা হয়েছে; “চলতি মাসের ভাড়া” নয়।
2. মাসিক/বার্ষিক Excel export-এর XLSX ZIP/XML কাঠামো পরীক্ষা করা হয়েছে; সারসংক্ষেপ ও বিস্তারিত শিট থাকে।
3. ভাড়া আদায় ও বকেয়া রিপোর্টে ফ্লোরভিত্তিক দোকান, মাসিক ভাড়া, পূর্বের বকেয়া, চলতি মাসের বকেয়া, বকেয়া মাস, অগ্রিম ভাড়া, অগ্রিম মাস, অপেক্ষমাণ চেক ও মোট বকেয়া দেখানো হয়। Excel-এ প্রতি ফ্লোর আলাদা শিট।
4. দোকান সম্পাদনায় “ভাড়া শুরু হওয়ার মাস” যোগ করা হয়েছে। পুরোনো দোকানের বকেয়া মাস সঠিক পেতে এই মাস অথবা চুক্তির শুরুর তারিখ দিতে হবে। কোনো শুরুর তারিখ না থাকলে রিপোর্ট নির্বাচিত মাস থেকে হিসাব শুরু করবে এবং সতর্ক করবে।
5. চেকের পাসের শেষ তারিখ পার হলে অ্যাপ খোলা থাকা অবস্থায় Chrome Notification একবার দৈনিক দেখানোর ব্যবস্থা আছে। Chrome-এ notification permission দিতে হবে।
6. Print/PDF-এর সময় print CSS class দ্রুত সরিয়ে ফেলার সমস্যা বাদ দেওয়া হয়েছে; print dialog বন্ধ হলে class পরিষ্কার হবে।

ইনস্টল:
GitHub Pages-এর root-এ ZIP-এর ফাইলগুলো upload করুন। index.html overwrite করার আগে বর্তমান ফাইল ও JSON data backup রাখুন। একই GitHub Pages address ব্যবহার করলে browser localStorage-এর ডেটা সাধারণত একই origin-এ থাকবে; তবু backup ছাড়া কোনো পরিবর্তন করবেন না।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- Firebase live login/Firestore rules এই পরিবেশে আপনার প্রকৃত Firebase project-এ পরীক্ষা করা হয়নি।
- Chrome notification পেতে সাইট HTTPS-এ খুলতে হবে এবং notification permission Allow করতে হবে। এই static সংস্করণে অ্যাপ বন্ধ থাকলে server push notification পাঠানো যায় না; সতর্কতা অ্যাপ খোলা থাকলে কাজ করে।
- দোকানের পুরোনো বকেয়া সঠিক করতে প্রতিটি দোকানের rent start month বা contract start date যাচাই করুন।
