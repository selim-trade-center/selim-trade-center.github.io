SELIM TRADE CENTER MANAGEMENT SYSTEM — FINAL BUILD v16

এই ZIP ফাইলে আছে:
1) index.html — মূল সফটওয়্যার
2) sw.js — অফলাইন ক্যাশ/সার্ভিস ওয়ার্কার
3) README-BN.txt — এই নির্দেশনা

GitHub Pages-এ আপডেট করার নিয়ম:
1. ZIP ফাইলটি Android-এর My Files/Files অ্যাপে Extract করুন।
2. GitHub-এ আপনার Selim Trade Center repository খুলুন।
3. repository-এর আগের index.html এবং sw.js ফাইল Replace করে এই ZIP-এর নতুন index.html ও sw.js আপলোড করুন।
4. README-BN.txt GitHub-এ আপলোড করা বাধ্যতামূলক নয়।
5. GitHub Pages deploy সম্পন্ন হলে ওয়েবসাইট খুলে একবার Reload করুন। পুরোনো সংস্করণ দেখালে Chrome-এ সাইটটি বন্ধ করে আবার খুলুন; প্রয়োজনে দুইবার Reload দিন।
