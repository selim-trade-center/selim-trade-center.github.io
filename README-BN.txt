Selim Trade Center - Final Report Update
======================================

এই প্যাকেজে index.html হলো আপডেট করা অ্যাপ ফাইল।

যে রিপোর্ট সুবিধাগুলো কোডে রাখা/সংশোধন করা হয়েছে:
1. মাসিক আর্থিক স্টেটমেন্ট: আয়, ব্যয়, নিট উদ্বৃত্ত, নগদ/ব্যাংক, খাতভিত্তিক হিসাব এবং দোকানভিত্তিক আদায়ের সারাংশ।
2. মাসিক ও বার্ষিক আর্থিক Excel এক্সপোর্ট: সারসংক্ষেপ ও বিস্তারিত লেনদেন আলাদা শিটে।
3. ফ্লোরভিত্তিক ভাড়া আদায় ও বকেয়া রিপোর্ট: দোকানভিত্তিক মাসিক ভাড়া, পূর্বের/চলতি বকেয়া, বকেয়া মাস, অগ্রিম ভাড়া, অপেক্ষমাণ চেক।
4. ফ্লোরভিত্তিক ভাড়া-বকেয়া Excel এক্সপোর্ট।
5. চেকের পাসের তারিখের সতর্কতা; অ্যাপ খোলা থাকলে Chrome notification permission দেওয়া থাকলে notification দেখানোর চেষ্টা করে।
6. মাসিক স্টেটমেন্টের প্রিন্ট লেআউট A4 Landscape-এ সংক্ষিপ্ত করা হয়েছে; চার্ট ও লেনদেনের দীর্ঘ তালিকা স্ক্রিনে থাকবে, প্রিন্টে থাকবে না।

ব্যবহার:
- ZIP Extract করুন।
- GitHub Pages-এর বর্তমান index.html-এর ব্যাকআপ রাখুন।
- Extract করা index.html দিয়ে রিপোজিটরির index.html প্রতিস্থাপন করে commit/push করুন।
- আগের একই ওয়েব ঠিকানায় চালালে browser localStorage-এর পুরোনো তথ্য সাধারণত একই origin-এ থাকবে; তবু আগে অ্যাপের Backup থেকে JSON ব্যাকআপ নিন।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- Chrome notification কেবল অ্যাপ/পেজ চালু থাকা অবস্থায় চেক করা যায়। ওয়েবসাইট বন্ধ থাকলে বা ফোনে ব্রাউজার বন্ধ থাকলে সার্ভার/Push backend ছাড়া নির্ভরযোগ্য background notification সম্ভব নয়।
- বাস্তব Firebase অ্যাকাউন্ট, বাস্তব ডেটা, এবং ফিজিক্যাল প্রিন্টার দিয়ে পরীক্ষা করা হয়নি।
- মাসিক Excel generator-এর নমুনা .xlsx ফাইল তৈরি করে OpenPyXL দিয়ে খোলা ও worksheet data যাচাই করা হয়েছে।
- JavaScript inline script syntax check এবং ZIP integrity check করা হয়েছে।
