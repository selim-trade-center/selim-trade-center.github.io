# Selim Trade Center App — প্রাথমিক প্যাকেজ

## এতে যা আছে
- লগইন স্ক্রিন
- মোট ২টি অ্যাকাউন্ট: Admin (পূর্ণ নিয়ন্ত্রণ) এবং Manager + Accountant (দোকান/চুক্তি ও হিসাব—দুই ধরনের কাজ)
- দোকানের মন্তব্য কলাম, একাধিক বকেয়া মাস উল্লেখ, লাল নোটিশ বোর্ড, A4 স্টেটমেন্ট প্রিন্ট/PDF, ভাড়া/বিল, চুক্তিপত্র, রিপোর্ট ও JSON ব্যাকআপ
- PWA manifest, অ্যাপ আইকন ও offline service worker

## প্রাথমিক লগইন
- Username: `admin`
- Password: `Admin@123`

প্রথম লগইনের পর Admin প্যানেল থেকে একটিমাত্র Manager + Accountant অ্যাকাউন্ট তৈরি করুন। মোট ইউজার হবে ২ জন।

## ইনস্টল করার জন্য
এই প্যাকেজটি HTTPS সমর্থিত কোনো হোস্টিংয়ে আপলোড করতে হবে। এরপর:
- Android Chrome: সাইট খুলে মেনু থেকে **Install app** বা **Add to Home screen**
- Windows Chrome/Edge: ঠিকানার পাশে Install আইকন বা মেনু থেকে **Install this site as an app** নির্বাচন করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি এখনো প্রাথমিক/ডেমো সংস্করণ। লগইন তথ্য এই ব্রাউজারের localStorage-এ থাকে; এটি নিরাপদ সার্ভার-ভিত্তিক authentication নয়। Admin/Manager/Accountant পার্থক্য মূলত অ্যাপের ভেতরের UI নিয়ন্ত্রণ। বহু ডিভাইসে একই ডেটা স্বয়ংক্রিয়ভাবে ভাগ হয় না। Google Drive sync এখনো সংযুক্ত নয়। বাস্তব ব্যবসার সংবেদনশীল তথ্য ব্যবহারের আগে নিরাপদ ব্যাকএন্ড, password hashing, HTTPS hosting ও sync ব্যবস্থা তৈরি/পরীক্ষা করতে হবে।

## ডেটা
তথ্য আলাদা আলাদা ডিভাইস/ব্রাউজারে থাকে। নিয়মিত JSON backup নিন এবং অন্য ডিভাইসে Restore ব্যবহার করুন। ব্যাকআপ ফাইলে ইউজার অ্যাকাউন্টের তথ্য থাকতে পারে—ফাইলটি গোপন রাখুন।
